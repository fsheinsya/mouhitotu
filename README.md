# ゲームタイトル 毛一つ

## 概要

「毛一つ」は、おじさんの毛を集めてポイントを獲得し、さまざまな種類の毛を図鑑に登録していく収集系ブラウザゲームです。

プレイヤーは時間経過で生えてくる毛を集めながら、ポイントを使ってアイテムを活用します。
育毛剤を使うと毛が生える速度が上がり、高級育毛剤を使うとレアリティの高い毛が出現しやすくなるなど、収集のテンポや達成感を意識して設計しました。

## 工夫した点

本作では、一部のソースコード作成に生成AIを活用しましたが、AIに頼りきるのではなく、自分でゲーム全体の構造を考えながら制作しました。

特に、クラス構造を意識して処理を整理し、紙に設計を書きながらUIの配置やゲームの流れを決めました。
また、毛の種類やレアリティ、アイテム効果、図鑑機能などを組み合わせることで、短時間でも「集める楽しさ」が感じられるゲームになるよう工夫しました。

その結果、約1週間でブラウザ上で遊べる形まで制作することができました。

## これからの改善点・やってみたいこと

現在ブラウザで公開していますが、公開時に一部の環境で毛が表示されない不具合が発生しています。今後は、ビルド後の挙動や表示処理を確認し、原因を特定して修正していきたいです。

また、実績システムの追加にも挑戦したいと考えています。
例えば「毛を100個集める」「レアな毛を初めて入手する」といった目標を用意することで、プレイヤーが継続して遊びたくなるモチベーションを作れると考えています。
