# タイトル名「毛一つ」

## 公開URL
ブラウザ上でプレイできます。
URL： https://unityroom.com/games/mouhi1tsu

## 概要
「毛一つ」は、神様の毛を集めてポイントを獲得し、さまざまな種類の毛を図鑑に登録していく収集系ブラウザゲームです。

プレイヤーは時間経過で生えてくる毛を集めながら、ポイントを使ってアイテムを活用します。
育毛剤を使うと毛が生える速度が上がり、高級育毛剤を使うとレアリティの高い毛が出現しやすくなるなど、収集のテンポや達成感を意識して設計しました。

## GitHubについて
制作当時のGit管理に不備があり、完成時点のプロジェクトをリモートに送り切れず、
製作途中のプロジェクトのみの公開となります。(下記反省点に詳細を記しました)
そのため、本リポジトリでは主要な実装部分や設計意図を中心に整理しています。

## 実装した主な機能
- 時間経過によるキャラクター成長
- キャラクター収集
- スコア獲得
- ScriptableObjectによるデータ管理
- レア度・成長速度・抽選重みの管理
- アイテム購入による強化要素

## 工夫した点
キャラクターごとのパラメータをScriptableObjectで管理し、
コード内に直接値を書きすぎないようにしました。
また、重み付き抽選を使うことで、レア度ごとに出現しやすさを変えました。

本作では、一部のソースコード作成に生成AIを活用しましたが、AIに頼りきるのではなく、自分でゲーム全体の構造を考えながら制作しました。

特にクラス構造を意識して処理を整理し、紙に設計を書きながらUIの配置やゲームの流れを決めました。
また、毛の種類やレアリティ、アイテム効果、図鑑機能などを組み合わせることで、短時間でも「集める楽しさ」が感じられるゲームになるよう工夫しました。

その結果、約1週間でブラウザ上で遊べる形まで制作することができました。

## 反省点

現在ブラウザで公開していますが、公開時に一部の環境で毛が表示されない不具合が発生しています。今後は、ビルド後の挙動や表示処理を確認し、原因を特定して修正していきたいです。

また、実績システムの追加にも挑戦したいと考えています。
例えば「毛を100個集める」「レアな毛を初めて入手する」といった目標を用意することで、プレイヤーが継続して遊びたくなるモチベーションを作れると考えています。

さらに、githubの扱いに慣れておらず、データが一部消えてしまうという事故が発生したので、今後はバックアップをしっかりととることや、フォント（Textmeshpro）のデータが原因でリモートに送れなかったので、ローカルで調整した結果一部データが消えたのでもっとしっかりと運用していきたいと思いました

制作当時はUnityプロジェクトのGit管理への理解が浅く、
不要ファイルの除外や提出用リポジトリの整理が十分ではありませんでした。
さらにgitの操作を誤って、完成品の構成を削除してしまったので、当リポジトリでは制作途中のリポジトリとなっています。
